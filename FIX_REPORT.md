## Evidence scope and deliberate choices

- Gender rules deliberately ship with neutral factor `1` for both choices. The editable `resultRules` hooks support wording/soft weights/exclusion, but this repair does not invent gender-based career differences or stereotypes. This differs from a requirement for different default scores by gender; all four combinations still produce valid results.
- Careers show actual selected answer evidence plus **illustrative field-level** work examples and experiments; these are not invented professional biographies or verified daily-work profiles for all 166 occupations. Mismatch checks prompt exploration rather than silently excluding careers.
- Exports are real downloadable PDFs generated entirely on-device. Pages embed rendered app-font images so English, Russian and Uzbek remain legible. The PDF is not selectable/tagged text; the HTML report remains the accessible reading surface. The share image stays local until an explicit share action.
- Older stored reports cannot recover answers that were never retained. They show the full report that exists and disclose missing evidence; no history is fabricated.
- Baseline screenshots were reconstructed from the original source because generated captures are not committed. Visual review uses 36 comparable page/width pairs; the broader language/theme capture matrix covers 360 cases. Changes intentionally improve wrapping and hierarchy while retaining existing tokens, fonts and motion.
- The continuation grouped repairs that share result/account code and resumed existing audit commits. Focused checks ran per repair, followed by the final integrated suite; a separate full-suite pass after every phase is not available. Local failing reproduction logs are retained where possible. Already-fixed upstream defects were reverified without reverting them.
- Browser tests run Chromium device emulation, including touch, reduced motion, keyboard-sized viewports, enlarged text and reflow. They do not establish physical-device Safari/Firefox behavior or live email/database operation. External bot blocks/timeouts are reported honestly; no replacement URL was guessed.
