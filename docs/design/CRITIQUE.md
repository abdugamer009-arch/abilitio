# Self-critique — rejected flagship version

Captured before any source changes on 9 October 2026 at 1440×900 and 390×900. Evidence: `../abilitio-rebuild-delivery/before/`: twenty intro frames per viewport, three frames at each 650 px scroll stop, full-page images and console log. Desktop height 4218 px; mobile 5564 px. No captured console errors; functional cleanliness does not establish design quality.

| ID | Location | Failure and reason | Required replacement |
|---|---|---|---|
| C01 | Home hero / index.tsx | “A mind full of possibilities” describes almost any education brand. A first-time visitor must read supporting copy to learn what to do. | Specific student outcome, one verified structural proof number, two different commitments. |
| C02 | Hero composition / styles.css | Oversized serif copy beside a floating object is a familiar portfolio pattern. The brain occupies half the first screen without revealing the product. | Instrument/workbench composition: promise, indexed signals and a working product destination. |
| C03 | BrainCanvas cortexPoint/buildSkin | Half-shell parameterization creates an open medial surface. Low-resolution displaced geometry shows hard triangular patches. Translucency makes those patches look broken. | Closed hemispheres, compressed medial walls, deeper organized sulci and stable normals. |
| C04 | BrainCanvas shaders/materials | Pale additive particles on paper lose their silhouette. Gray transparent surfaces resemble a technical prototype. The fissure reads as a crack; lighting does not describe folds consistently. | Dark dedicated scene, deliberate ceramic surface, distinct rim, controlled colored network. |
| C05 | BrainScene intro | Poster disappears on the first frame before the assembly is legible. “Preparing study” is vague, and the small progress bar has no relationship to the hero reveal. | Real asset completion, coordinated masks and a separate understandable scene assembly. |
| C06 | MotionProvider [data-reveal] | Every heading receives the same y=24/power3.out tween and modulo-three delay. Elements move independently of meaning or surrounding content. | Labelled section timelines with distinct title, rule, panel and detail phases. |
| C07 | Hero/styling | CSS entry animation and later dynamic GSAP run without one authoring clock. There is no deliberate title → proof → action → object sequence. | Masked words and overlapping labelled hero timeline after actual core assets resolve. |
| C08 | Signal bars / MotionProvider | Three scrubbed bars fill because the page scrolls. They do not express a result, difficulty or actual progress; visually they suggest measurement. | Actual answered-item progress and recorded tasks; scroll movement only shapes the story. |
| C09 | Homepage method rows | The three signals are explained here, in the hero and again in the sample. This is repeated documentation, not product demonstration. | One selectable workbench showing questions, profile and path in the same interface. |
| C10 | Homepage sample | Three broad invented choices sit in a bordered box. It does not show the actual assessment question bank, correct reasoning or a usable report. | A real bank question, shared answer interaction, complete solution and traceable local demo report. |
| C11 | Homepage evidence/FAQ/CTA | Several similarly weighted sections and repeated CTA copy stretch mobile to 5564 px. Most of that distance contains text rather than evidence. | Shorter page; one product workshop, a compact trust block and honest access comparison. |
| C12 | Founder presence | No visible person near the first interaction. Founder initials elsewhere are anonymous decoration. | Clearly marked photo and approved first-person-bio slots; no invented face or biography. |
| C13 | Cursor/magnet / MotionProvider | Direct pointer transforms snap. Pointerout resets the magnet even while crossing a button's children. There are only generic action/read cursor states. | Eased tracking, relatedTarget-aware exits and contextual choose/explain/open states. |
| C14 | Global routes / PageShell | A generic page animation is the only transition. There is no authored exit or coherent entry on navigation. | Route curtain/clip transition with cleanup; preserve keyboard and normal modified-link behavior. |
| C15 | Footer/Navbar | Four footer columns compete with the main CTA; language and theme controls dominate small headers. | Four navigation destinations and a compact utility footer. |
| C16 | Pricing/product trust | “Free” is stated but not demonstrated in the content list. There is no tangible preview of the path/results. | Free activities and actual working previews. No artificial Pro tier, discount or billing control. |
| C17 | Verification/report | Good automated scores were treated as evidence of a studio-grade experience. Frame sequences and an honest motion critique were missing. | Stage screenshots plus motion frames; report visual decisions separately from functional/performance checks. |

The previous version failed the creative brief. Retain its tested security/backend fixes, but rebuild the public product presentation, choreography, brain surface, navigation and visual system. Do not use claimed school reach as measured impact. Unknown founder facts and pilot numbers must remain explicit TODOs.
